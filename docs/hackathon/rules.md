# Burning Token — Rules & Constraints

Source: https://app.burningtoken.dev/rules + `get_hackathon_brief` MCP
Saved: 2026-09-09 · Platform last updated: 2026-09-07

## Deadline

- **Global submission closes: 2026-09-14T02:59:00Z** = Sunday Sept 13, 23:59 ART (UTC−3) = **Sept 13, 7:59 PM PDT**
- The SF in-person deadline (Sept 5, 4:00 PM PDT) has passed — that was the local
  in-person judging track only. The global competition is what's live.
- Saving a draft does NOT submit. You must click Submit.
- You can keep editing and updating after submitting, until the deadline.

## Teams & entries

- Teams: 1–3 people.
- **One person can be on up to 5 active teams = up to 5 separate projects/submissions.**
- One entry per project.

## What you're allowed to build

- May start from an idea, prototype, or existing codebase.
- Must clearly identify what existed **before September 5** vs. what was built during the event.
- **Only the new work is evaluated.** Submitting an unchanged existing product does not qualify.
- Keep a starting commit / release / equivalent record plus a clear changelog.
- Templates, open-source libraries, APIs, and AI coding tools are allowed with proper
  attribution and licenses. You need permission for all third-party code, data, assets,
  and likenesses.

## Submission requirements (all required unless noted)

- Project name + team members
- **Oneliner**
- **Qué es y para quién** (what it is and who it's for)
- **Public project URL** — anyone can open or install it, no private login
- **X post containing a demo video ≤ 2 minutes** — screen recording, on-camera pitch, or
  both. Must **tag @nerdconf_ar** in the post or a comment. LinkedIn does not count.
  There is no separate video field; the demo lives in the X post.
- **Challenges** selected + **evidence per challenge**: which technology is integrated,
  what role it plays, and how a judge verifies it
- **Which AI tools were used to build it**
- Work summary with credits; test account access if needed
- GitHub is **optional** — publishing code or granting repo access is not required

## Scoring — 100 points, same shape in every track

| Weight | Fun Build (NERDCONF) | Sponsor challenges |
|---|---|---|
| **35** | Shipping | Shipping |
| **25** | Originality | Usefulness |
| **25** | Fun | Track-specific (research quality / realtime / output quality / reliability / paid experience) |
| **15** | Execution | Integration |

**Shipping is 35% in every single track** — the largest single criterion. A judge being
able to open a link and use the thing outweighs every other consideration.

## Eligibility & disqualification

- Must be 18+ and legally eligible to receive a prize.
- Judges cannot compete in challenges they judge.
- Disqualifying: plagiarism, fabricated results, harassment, judging manipulation,
  unauthorized data exposure, testing without authorization.
- **For sponsor prizes: missing the required integration = ineligible, not just −15 points.**
  Naming a sponsor, creating an account, or showing a logo is not an integration.

## Prizes

- 5 × USD 500 cash (Linkup, RevenueCat, Convex, Nebius, NERDCONF Fun Build)
- Render: USD 900 in **credits**, split 500 / 300 / 100 — the only track with 3 placements
  and the only one that isn't cash
