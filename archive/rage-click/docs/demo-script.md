# Demo script (short, per "Show us" requirement)

Target length: 20–30 seconds. No narration needed beyond a caption/title card —
the interaction should read on its own.

1. Open the page cold — show the calm state ("go ahead, tap it.").
2. Tap slowly a few times — show the taunt text changing, meter rising a
   little, face going from neutral to annoyed.
3. Tap rapidly in a burst — show shake amplitude increasing, screen tinting
   red, cracks appearing, sound getting angrier/louder.
4. Push it to the break point — show the glitch-out and surrender screen with
   the click count / time stat.
5. Hit "do it again" to show it resets cleanly.

## Access for judges

- Link to the hosted build goes here once deployed (e.g. GitHub Pages /
  Vercel / Netlify — pick whichever is fastest to set up).
- No account, hardware, or install required — link + a browser tab is enough.
